# My Tech Stack

Building premium web experiences requires a solid foundation. Here's a look at the stack I reach for on most projects.

## Framework: Next.js

Next.js (specifically the App Router) is my go-to. It provides incredible performance, SEO benefits, and an excellent developer experience.

## Styling: Tailwind CSS

Tailwind CSS lets me build custom designs quickly without leaving my HTML. The new version 4 makes it even faster and leaner.

## Backend: Supabase

For anything requiring a database, Supabase is fantastic. It's essentially an open-source Firebase alternative powered by PostgreSQL.
